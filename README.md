# Two stages · 主图批量生成

把竞品图拖进来，工具会自动：

1. 认出它是哪个品类、哪个款式（比如「相框 · 横版」）；
2. 把商品上的图案提取成一张干净的**素材图**；
3. 按这个品类设定好的模版，生成**主图**；
4. 识别主图的**场景、关键词、可定制项**；
5. 如果有名字、照片这类买家要定制的内容，再生成一张把这些位置留空的**空白图**。

一批图里可以混着不同品类，运行中也能随时继续加图。认不出来或出了问题的图会放进「需处理」，不会卡住其他图。

## 一、第一次使用

### 1. 安装 Node.js（只需一次）

到 <https://nodejs.org/zh-cn> 下载「长期支持版（LTS）」并安装，一路下一步即可。版本需要 20.19 或更新。

### 2. 启动

- **Mac**：双击 `双击启动.command`。
  第一次如果提示「无法打开，因为来自身份不明的开发者」，请**右键点它 → 打开 → 再点一次打开**，以后就能直接双击了。
- **Windows**：双击 `双击启动.bat`。

第一次启动会自动安装一个图片处理组件（需要联网，大约 1 分钟）。之后浏览器会自动打开工具页面。

> 启动后会出现一个黑色窗口，**这个窗口要一直开着**，关掉它工具就停了。
> 页面关掉、也没有图在跑超过 10 分钟，工具会自己退出，下次再双击启动即可。
> 已经在运行时再双击，只会重新打开页面，不会开两份。

### 3. 填写接口

点页面右上角的 ⚙ 设置：

| 组 | 填什么 |
|---|---|
| 生图接口 | 中转站地址（通常以 `/v1` 结尾）、Key、模型（默认 `gpt-image-2`） |
| 分析接口 | 中转站地址、Key、模型（默认 `gpt-5.6`）。可以和生图用同一个中转站 |

每组填好后点「测试连接」，显示「连接成功」就可以了。所有输入框改完会**自动保存**（看到「已保存」小字），不需要点保存按钮。

右上角两个小圆点就是两个接口的状态：绿色正常，黄色还没配置，红色表示 Key 无效（对应的步骤会暂停，改好 Key 后自动继续）。

### 4. 建模版库

点顶部的「模版库」。左边是品类列表，右边编辑选中的品类。

1. **新增品类**：起个名字，比如「相框」。
2. **AI 识别说明**：写一句话帮 AI 认出它，比如「挂墙帆布画/相框，图案印在矩形画面上」。
3. **款式**：同一品类有横竖之分就加两个款式，比如「横版 3:2」「竖版 2:3」。比例是**图案本身**的宽:高，也就是商品上印图案那一块表面的形状（比如花园灯是灯罩上那块细长的透光面板），不是整张图的比例。拿不准就上传白底图后点比例旁边的「AI 帮我估算」，看建议再点「采用」。只有一种就保持「单款式」，改一下比例即可。
4. **主图模版**：
   - **默认 · 贴图**：把素材图贴到这个款式的**白底图**上。每个款式都要上传一张白底图（商品空白、没有图案的照片）：直接点虚线框选图，或把图片拖进框里。
     - **贴图方式**（配方卡下面，2026-10-27 新增）：「自动判断」会看白底图——商品是正对镜头的矩形或圆形（比如铝板画），就用**本地合成**：直接把素材图覆盖到商品上，印刷面里只看得到素材图，安装孔保留，不调用 AI、不花额度；斜拍或形状不规则的，用 **AI 贴图**。配方卡上会显示现在用的是哪种、自动判断的理由，也可以手动改成「本地合成」或「AI 贴图」。改了之后新加的图生效；已经生成的图在详情里重做「生成主图」就会按新方式来。
   - **+ 自定义模版**：写自己的提示词，可以配一张**参考图**（可不配）。
   - **每个款式的主图模版是分开的**：先在上面选中款式（比如「圆形」），再添加、修改它的模版；自定义模版、提示词、参考图、正在使用哪个模版，都只属于这个款式，改了不影响其他款式。默认模版「贴图」也是用各款式自己的白底图。
   - 选好后点「设为「圆形」使用」（单款式品类显示「设为本品类使用」）。
5. 中间的「发送给生图模型」卡片，就是实际会发给 AI 的内容：图 1、图 2 是哪张图，最前面系统自动加的那句话，以及提示词。**这里显示什么，就发送什么。**
   - 黄色提示：比如提示词里写了「第二张图片」，但这个款式只会发一张图，请补上参考图或改提示词。
   - 列表里品类旁边的红点表示缺白底图，黄点表示有提醒。

提示词里可以用 `{品类}`、`{款式}`、`{比例}`，会自动换成识别结果和款式比例。

左侧最上面的「全局提示词」是所有品类共用的「提取素材图」和「贴图」提示词，一般不用改。某个品类老出同一种问题（比如毛毯折过扶手的边被当成新的一排），在这个品类的「提取素材图」里点「单独设置」，只写这种材质特有的要求，不影响其他品类。

### 5. 识别父体（可选）

在设置里的「父体匹配」打开「识别父体」。先在飞书父体表的「… → 更多 → 添加文档应用」给当前应用阅读权限，再填父体表链接，点「读一下试试」。SP-API 凭证从 `通用提示词.rtf` 导入，或粘贴其中的文字，导入后店铺 ID、Client ID、Secret 和 Refresh Token 都只显示末 4 位。测试连接成功后，跑到第 ⑥ 步的图会按品类对应的标签页匹配父体。

模版库每个品类可以在「父体表标签页」里选对应标签页；默认使用和品类同名的标签页。没有读过表时，先回设置读一次，之后下拉框会出现标签页列表。

### 6. 识别父体结果

「识别信息」表在队列里出现父体结果后会增加「父体」和「下一个变体名」两列。已有父体会显示 SKU、主题、ASIN 和复制按钮；推荐变体名也能复制，并可用 ▲ ▼ 上下调一格，工具会跳过店铺里和同一批已经占用的编号。把握较低的结果标为「待确认」，可以点「去确认」打开详情第 ⑥ 步。

AI 判断表里没有合适的父体时，会按该标签页已有 SKU 的命名方式给出「建议新建」的父体 SKU 和 `Design 01` 起的变体名，只提供建议，不会创建商品；详情里还会列出前缀、主题、参照的表中 SKU 和试过的主题。没有父体结果时表格不显示这两列；已经有结果后关闭开关，已有结果仍会保留。

同一批里已经分过的变体编号会一直占用，即使图被「清除已完成」或移出队列，后面的图也会继续往后排。点「清空队列」开启新批次后，才重新按店铺实际子体和新队列计算。导出的 CSV 会追加父体主题、父体 SKU、父体 ASIN、建议变体名、父体把握、父体状态六列；旧批次行会自动补空值。

## 二、日常使用

### 加图

在「工作台」把竞品图**拖进上面的虚线框**，也可以点「选择图片」「选择文件夹」。

也可以粘贴：在访达（Windows 是文件资源管理器）里选中图片或整个文件夹按 ⌘C / Ctrl+C，回到工作台按 ⌘V / Ctrl+V，会用原文件名加入队列；截图、网页上「复制图片」后也能直接粘贴。运行中随时可以继续加，新加的排在后面。

### 看进度

- **队列**：每张图一行，依次是素材图 → 主图 → 空白图。转圈表示正在生成，红叉表示失败，「无需」表示这张图没有需要留空的内容。
- 点已生成的缩略图看**大图原图**：左右方向键或底部按钮在竞品图、素材图、主图、空白图之间切换，Esc 关闭；大图右上角「这一步的详情 / 重做」可以跳到详情。
- 点行尾的 ›（或生成中、失败的格子）打开详情，可以看到每一步**实际发给 AI 的图片和提示词**，以及结果。详情和模版库里的图片也都能点开看大图。
- 右上角「暂停队列」：已经在生成的会跑完，新的先不开始；点「继续队列」恢复。
- 「清除已完成」只移走跑完的图；「清空队列」移走队列里所有的图（要再点一次确认），正在生成的会先停下，暂停时也能清空。两种都不会删已经生成的文件。点「清空队列」后，再加的图会放进新的文件夹（见「三、输出在哪」）。

### 需处理

出问题的图会放到「需处理」，写明原因并给出按钮：

| 情况 | 怎么处理 |
|---|---|
| 没找到对应品类 | 下拉框选一个品类后「放回队列」；或「新建品类」；或「重新识别」 |
| 缺白底图 | 点「去上传白底图」，上传后这张图会**自动**回到队列 |
| 生成失败 | 一般是中转站暂时出问题，点「重试」 |
| 内容被拒 | 点「查看详情」，改一下提示词后重做 |
| 主图没过验收 | 左右对比素材图和主图，看问题清单（比如「贴图：印刷面右边露出了金属边」）。点「重新生成」重做主图，或「仍然使用」 |
| 素材图没过验收 | 左右对比竞品图和素材图，看问题清单（比如「文字变了：原图 THE BENNETT FAMILY → 素材图 AND A HAPPY NEW YEAR」「四边有白边」）。点「重新提取」可以改提示词再提一次（会重新验收）；觉得能用就点「仍然使用」；品类认错了就选一个品类点「换品类」 |

处理完的图会排到队尾，不会插到别的图前面。

### 先找印刷面，再提取（2026-10-27 新增）

识别品类时，AI 会顺便标出竞品图里商品印刷面（印着图案的那一整块，包括印在上面的边框、做旧边）的四个角。工具在本地把这四个角往外校正到商品的真实边缘，按透视拉正后，只把这一块交给 AI 做成素材图。墙面、拿着它的手、相框的木框都在区域外面，不会混进素材图；印在面上的边框也不会被当成产品边框去掉。

打开详情第 ① 步，可以看到竞品图上画出的提取区域（实线）。AI 没标出位置时，照旧按整张竞品图提取。

### 素材图验收（2026-10-27 新增）

素材图提取出来后，会先和竞品图对比，合格了才生成主图：

- **文字**：AI 把两张图上的文字分别逐字抄下来，由程序比对，大小写和标点不算，缺字、多字、改字都不合格。
- **图案**：AI 比对人物、动物、装饰这些元素有没有缺、多、变样，给一个相似分，低于设置里的阈值（默认 0.9）不合格。
- **四边**：竞品图印刷面四周印着的边框、做旧边、锈迹也是图案的一部分，素材图里少了（或者多出金属边、圆角、安装孔）都不合格。
- **边框外延**（2026-10-29 新增）：拼格毛毯这类四周一圈格子的图案，提取时容易往外多补半圈格子。工具会单独再问一次 AI，看素材图四边有没有被画布切掉一半的格子、有没有多出一排，有就不合格。没有格子边框的图几秒就返回；这项检查没请求成功时不拦，详情里写明「没检查成」。
- **颜色**：竞品图上印图案那一块和素材图比色差（ΔE），超过设置里的「色差阈值」（默认 5，人眼大约 2 以上开始能看出来）不合格，会写明是偏黄、偏红、偏暗还是偏艳。只拦下来，不自动改色。
- **版面**：本地检查四边有没有白边、圆角、边框，比例对不对（4:5、3:7 这类生图接口画不出来的比例不检查）。

截屏这类带显示器色彩配置的图，加进来时会先转成标准的 sRGB，保证 AI 看到的颜色和你在电脑上看到的一样。

每张图会多发一次分析请求。设置里可以关掉「素材图验收」，也可以改阈值。验收结果在详情第 ② 步里能看到，包括实际发给 AI 的内容和 AI 的原始回复。

主图生成后还有一道**主图验收**（2026-10-27 新增）：和素材图对比文字、图案、颜色，并检查印刷面有没有铺满、有没有露出铝板底色。本地合成的主图在本地核对，不花额度；AI 贴图的主图多发一次分析请求。没过的进「需处理」，可以「重新生成」或「仍然使用」。设置里可以单独关掉。

### 对结果不满意

打开详情，切到那一步，点「重做这一步」。可以临时改这一次的提示词（**只影响这一张，不会改模版库**），后面的步骤会自动跟着重跑。第 ① 步可以直接指定品类。主图是本地合成的，重做就是重新合成，没有提示词可改；想要 AI 版本，到模版库把这个款式的贴图方式改成「AI 贴图」再重做。

### 识别信息

「识别信息」标签汇总每张主图的场景、关键词、可定制项，每项都能一键复制；右上角选日期后「导出 CSV」，Excel 可以直接打开。

## 三、输出在哪

每批图一个文件夹，直接放在「下载」里（位置可以在设置里改）：

```
下载/
  主图生成-2026-10-27/             ← 当天第一批；清空队列后下一批是 -1、-2…
    相框/
      主图/
        HJ-mtfl671029101.png
      素材图/
        HJ-mtfl671029101.png
      空白图/
        HJ-mtfl671029101.png
    杯子/
      ...
    识别信息.csv
```

每个品类下按图的种类分三个文件夹，文件名就是这张图的 **SKU**（见下面「子体 SKU」），同一张图的主图、素材图、空白图同名，上架时直接打开「主图」文件夹拿图即可。品类没填 SKU 材质缩写时，文件名用上传时的原图名；同一批同一品类里有重名的文件，会自动加 `_2`、`_3`。

### 子体 SKU（2026-10-29 新增）

每张图认出品类后会分到一个子体 SKU，例如 `HJ-mtfl671029101`：店铺缩写 `HJ` - 材质缩写 `mtfl` + 年份末位 `6` + 地区标识 `7` + 月日 `1029` + 专属号 `1` + 当天序号 `01`。

- 材质缩写在模版库每个品类的「SKU 材质缩写」里填，通常就是飞书父体表前缀去掉专属号（`HJ-mtfl5` → `mtfl`）；不填就不生成 SKU。
- 店铺缩写、地区标识、专属号在设置的「SKU 命名」里改；专属号也用在「建议新建父体」的 SKU 里。
- 每个品类每天从 01 起，换一天重新从 01 起。发出去的号不收回：删图、清空队列、换批次、重启都接着往后排；同一张图重做不换号，换了品类才换号。
- 识别信息表多一列 SKU（可复制），导出的 CSV 第 2 列是 SKU。

怎么算「一批」（2026-10-27 改，原来按「日期-时间」和「有没有没跑完的图」划分，清空后新图还会进同一个文件夹）：**只有点「清空队列」才开新文件夹**。图跑完了但没清空，之后加的图继续放进同一个文件夹；「清除已完成」不算清空。文件夹名是 `主图生成-日期`，清空后下一批依次是 `-1`、`-2`……，「下载」里已经有同名文件夹就跳过；换了一天从新日期开始。工具重启后接着用原来的文件夹。重做某一步时，新结果会覆盖原来的同名文件。

## 四、把模版库分享给同事

在模版库左下角点「导出」（↓ 图标），得到一个 zip，发给同事。同事在自己的工具里点「导入」（↑ 图标）：

- **合并**：同名品类用你的版本覆盖，其他品类追加；
- **替换**：整个模版库换成你的（他原来的会自动备份到 `library/backups`）。

也可以直接把整个工具文件夹复制给同事。

> ⚠️ **不要把 `data` 文件夹发给别人**：里面存着你的中转站 Key 和任务记录。复制工具文件夹给同事前，先删掉其中的 `data` 文件夹。

## 五、常见问题

**页面打不开 / 显示连不上本机服务**
黑色窗口被关掉了，重新双击启动即可。

**提示「端口都被占用了」**
工具会从 3311 依次试到 3320，十个都被占用时才会这样。关掉其他程序后再试。

**一直「生成失败」**
先在设置里点「测试连接」。如果测试也失败，多半是中转站地址、Key 或网络的问题。

**设置里提示「中转站不支持保真参数，已自动关闭」**
有的中转站不认 `quality` / `input_fidelity` 这两个参数，工具已经自动去掉了，不影响使用。换了中转站可以重新打开。

**运行到一半电脑睡眠或关掉了窗口**
重新启动后，没跑完的图会从断点继续，已完成的不会重做。

## 给维护的人

- 开发：`npm install` 后 `npm run dev`（后端 3311 + 前端 5311）。
- 检查：`npm run typecheck`、`npm test`（全部使用模拟中转站和临时目录，不花额度、不碰真实数据）。
- 发布：`npm run build` 生成 `dist/`，`dist/` 要提交，同事拿到后不需要构建。
- 模拟中转站：`npm run mock`（端口 3999，地址填 `http://127.0.0.1:3999/v1`，Key 随便填）。
- 实现细节见 `docs/实施文档.md`。
