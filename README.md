# Two stages · 主图批量生成

把竞品图拖进来，工具会自动：

1. 认出它是哪个品类、哪个款式（比如「相框 · 横版」）；
2. 把商品上的图案提取成一张干净的**素材图**；
3. 按这个品类设定好的模版，生成**主图**；
4. 识别主图的**场景、关键词、可定制项**；
5. 如果有名字、照片这类买家要定制的内容，再生成一张把这些位置留空的**空白图**。

一批图里可以混着不同品类，运行中也能随时继续加图。认不出来或出了问题的图会放进「需处理」，不会卡住其他图。

## 一、第一次使用

### 1. 安装 Node.js（只需一次）

到 <https://nodejs.org/zh-cn> 下载「长期支持版（LTS）」并安装，一路下一步即可。版本需要 20.19 或更新。

### 2. 启动

- **Mac**：双击 `双击启动.command`。
  第一次如果提示「无法打开，因为来自身份不明的开发者」，请**右键点它 → 打开 → 再点一次打开**，以后就能直接双击了。
- **Windows**：双击 `双击启动.bat`。

第一次启动会自动安装一个图片处理组件（需要联网，大约 1 分钟）。之后浏览器会自动打开工具页面。

> 启动后会出现一个黑色窗口，**这个窗口要一直开着**，关掉它工具就停了。
> 页面关掉、也没有图在跑超过 10 分钟，工具会自己退出，下次再双击启动即可。
> 已经在运行时再双击，只会重新打开页面，不会开两份。

### 3. 填写接口

点页面右上角的 ⚙ 设置：

| 组 | 填什么 |
|---|---|
| 生图接口 | 中转站地址（通常以 `/v1` 结尾）、Key、模型（默认 `gpt-image-2`） |
| 分析接口 | 中转站地址、Key、模型（默认 `gpt-5.5`）。可以和生图用同一个中转站 |

每组填好后点「测试连接」，显示「连接成功」就可以了。所有输入框改完会**自动保存**（看到「已保存」小字），不需要点保存按钮。

右上角两个小圆点就是两个接口的状态：绿色正常，黄色还没配置，红色表示 Key 无效（对应的步骤会暂停，改好 Key 后自动继续）。

### 4. 建模版库

点顶部的「模版库」。左边是品类列表，右边编辑选中的品类。

1. **新增品类**：起个名字，比如「相框」。
2. **AI 识别说明**：写一句话帮 AI 认出它，比如「挂墙帆布画/相框，图案印在矩形画面上」。
3. **款式**：同一品类有横竖之分就加两个款式，比如「横版 3:2」「竖版 2:3」。比例是素材图的大致形状，不需要很精确。只有一种就保持「单款式」，改一下比例即可。
4. **主图模版**：
   - **默认 · 贴图**：把素材图贴到这个款式的**白底图**上。每个款式都要上传一张白底图（商品空白、没有图案的照片）。
   - **+ 自定义模版**：写自己的提示词，可以给每个款式配一张**参考图**（可不配）。
   - 选好后点「设为本品类使用」。
5. 中间的「发送给生图模型」卡片，就是实际会发给 AI 的内容：图 1、图 2 是哪张图，最前面系统自动加的那句话，以及提示词。**这里显示什么，就发送什么。**
   - 黄色提示：比如提示词里写了「第二张图片」，但这个款式只会发一张图，请补上参考图或改提示词。
   - 列表里品类旁边的红点表示缺白底图，黄点表示有提醒。

提示词里可以用 `{品类}`、`{款式}`、`{比例}`，会自动换成识别结果和款式比例。

左侧最上面的「全局提示词」是所有品类共用的「提取素材图」和「贴图」提示词，一般不用改。

## 二、日常使用

### 加图

在「工作台」把竞品图**拖进上面的虚线框**，或者直接 Ctrl/⌘ + V 粘贴，也可以点「选择图片」「选择文件夹」。运行中随时可以继续加，新加的排在后面。

### 看进度

- **队列**：每张图一行，依次是素材图 → 主图 → 空白图。转圈表示正在生成，红叉表示失败，「无需」表示这张图没有需要留空的内容。
- 点任意一张缩略图（或行尾的 ›）打开详情，可以看到每一步**实际发给 AI 的图片和提示词**，以及结果。
- 右上角「暂停队列」：已经在生成的会跑完，新的先不开始；点「继续队列」恢复。

### 需处理

出问题的图会放到「需处理」，写明原因并给出按钮：

| 情况 | 怎么处理 |
|---|---|
| 没找到对应品类 | 下拉框选一个品类后「放回队列」；或「新建品类」；或「重新识别」 |
| 缺白底图 | 点「去上传白底图」，上传后这张图会**自动**回到队列 |
| 生成失败 | 一般是中转站暂时出问题，点「重试」 |
| 内容被拒 | 点「查看详情」，改一下提示词后重做 |

处理完的图会排到队尾，不会插到别的图前面。

### 对结果不满意

打开详情，切到那一步，点「重做这一步」。可以临时改这一次的提示词（**只影响这一张，不会改模版库**），后面的步骤会自动跟着重跑。第 ① 步可以直接指定品类。

### 识别信息

「识别信息」标签汇总每张主图的场景、关键词、可定制项，每项都能一键复制；右上角选日期后「导出 CSV」，Excel 可以直接打开。

## 三、输出在哪

默认保存在 `下载/主图生成` 里（可以在设置里改）：

```
主图生成/
  2026-10-26/
    相框/
      原文件名_素材.png
      原文件名_主图.png
      原文件名_空白.png
    杯子/
      ...
    识别信息.csv
```

同一天同一品类里有重名的文件，会自动加 `_2`、`_3`。重做某一步时，新结果会覆盖原来的同名文件。

## 四、把模版库分享给同事

在模版库左下角点「导出」（↓ 图标），得到一个 zip，发给同事。同事在自己的工具里点「导入」（↑ 图标）：

- **合并**：同名品类用你的版本覆盖，其他品类追加；
- **替换**：整个模版库换成你的（他原来的会自动备份到 `library/backups`）。

也可以直接把整个工具文件夹复制给同事。

> ⚠️ **不要把 `data` 文件夹发给别人**：里面存着你的中转站 Key 和任务记录。复制工具文件夹给同事前，先删掉其中的 `data` 文件夹。

## 五、常见问题

**页面打不开 / 显示连不上本机服务**
黑色窗口被关掉了，重新双击启动即可。

**提示「端口都被占用了」**
工具会从 3311 依次试到 3320，十个都被占用时才会这样。关掉其他程序后再试。

**一直「生成失败」**
先在设置里点「测试连接」。如果测试也失败，多半是中转站地址、Key 或网络的问题。

**设置里提示「中转站不支持保真参数，已自动关闭」**
有的中转站不认 `quality` / `input_fidelity` 这两个参数，工具已经自动去掉了，不影响使用。换了中转站可以重新打开。

**运行到一半电脑睡眠或关掉了窗口**
重新启动后，没跑完的图会从断点继续，已完成的不会重做。

## 给维护的人

- 开发：`npm install` 后 `npm run dev`（后端 3311 + 前端 5311）。
- 检查：`npm run typecheck`、`npm test`（全部使用模拟中转站和临时目录，不花额度、不碰真实数据）。
- 发布：`npm run build` 生成 `dist/`，`dist/` 要提交，同事拿到后不需要构建。
- 模拟中转站：`npm run mock`（端口 3999，地址填 `http://127.0.0.1:3999/v1`，Key 随便填）。
- 实现细节见 `docs/实施文档.md`。
